应用区别：谁能干什么

不是替代，是分工
大模型 LLM System 2 · 秒级 · 分/厘级成本
  • 能干：写作、翻译、多步推理、复杂规划、代码生成
  • 不划算：只要一个判断，也付整段生成的钱
  • 已在生产：各家的客服机器人、Copilot、文档起草
企业例：智能客服 / 售前顾问。多轮澄清、写工单、出方案——需要「说人话」的环节全是它的主场；但「派单、急件」这类判断也用它，成本就在这里。
BERT 分类器 毫秒级 · 标签焊死
  • 能干：固定不变的单一分类（垃圾邮件、工单分类、风控打标）
  • 短板：换任务/加标签 = 重新标注 + 重训 + 发版
企业例：单据 / 工单批量分类。意图识别、邮件分拣、敏感条款筛查——任务固定时又快又省；但业务一变（新增「退货组」）就要重标注、重训、发版。
决策模型（Jev 等） System 1 · 毫秒 · 万分之一元
  • 能干：路由 · 闸门 · 质检 · 实时控制（改标准=改一个字符串）
企业例：邮件 / 工单入口闸门。每条来信一次前向同时判：钓鱼？（noul）→ 派哪个组（choice）→ 多急（score），≈30ms 全答完，低置信自动转人工（Laya 官方模板，我方已复现）。
判断下沉到快层，生成与推理留给 LLM —— Agent 调用量可降 40–70%（LangChain 官方路由中间件、Claude Code 安全钩子、Cloudflare 内部分流已在生产验证）
判断下沉到快层，生成与推理留给 LLM数据来源：厂商公开材料 + 第三方盘点〔三〕+ 我方实测〔我〕

决策模型已经能干什么

我方微调实例 + 社区公开案例 · 落地建议见完整报告 §7
判断类 AI 正在形成独立生态：「判断力」可以用自己的数据微调进去，也已经出现在社区各种 Agent 的关键关节上——从网页点击到安全审批。
我方微调实例：让决策模型学会「追食物」〔我〕
61ms / 步5 问一次前向撞死判断 AUC 0.99单卡 ≈3 小时
  • 同一局、同 60 步：基础模型吃 0 个（原地打转）→ 微调后吃 6 个（直线追食物）
  • 每步 5 个问题（走哪边 + 四方向会不会撞死）一次前向 61ms，撞死判断 AUC 0.99
  • 只训 26.5M 决策头（编码器冻结），单张消费级显卡约 3 小时
  • 再加回合级强化（GRPO）：线上成绩 8.2 → 9.2 食 / 100 步，离线指标无退化
  • 「打转」等顽固先验一个 epoch 即消除——先验住在决策头里，不在编码器
  • 微调的是「判断」而不是「语言」——不改变模型的其他能力
  • 4 万步数据自主采集——判断标准从此是自己的资产，不随供应商变动
含义：路由表、风控规则、质检标准——业务判断力可以用自有数据固化进 421M 的小模型。
