一句话结论

Jacobi 矩阵是"这个变换在局部看起来是什么形状"（旋转、拉伸、剪切，各方向各拉多少）； Jacobi 行列式是"这个变换在局部把体积放大了多少倍"。 而概率密度是"单位体积里的概率质量"，体积被放大 \(k\) 倍，密度就必须缩小 \(k\) 倍—— 这就是 flow 模型似然里那个行列式的全部来历。

理解这条链的关键在于尺度。仿射变换是"一个动作"，Jacobi 矩阵是"在每个点各挂一个动作"，行列式是"这个动作把面积改了几倍"。 三者其实是同一个几何对象的三种说法。

1仿射变换：线性变形的最小单元

1.1 线性变换：原点不许动的规则变形

一个映射 \(T:\mathbb{R}^2\to\mathbb{R}^2\) 是线性的，意思是它满足两条规矩：

\[ T(u+v)=T(u)+T(v),\qquad T(\lambda u)=\lambda\,T(u) \]

把这两条翻译成几何语言，就是：网格线还是网格线，等距的点还是等距的点，而且原点必须待在原地。 因为它自动有 \(T(0)=T(0+0)=T(0)+T(0)\Rightarrow T(0)=0\)。

这样一个变换完全由 \(2\times 2\) 矩阵决定：

\[ \begin{bmatrix}x'\\ y'\end{bmatrix}=\begin{bmatrix}a&b\\ c&d\end{bmatrix}\begin{bmatrix}x\\ y\end{bmatrix} \]
最关键的一句话

这个矩阵的两列，就是两根基箭头被送去的方向： \(\binom{1}{0}\mapsto\binom{a}{c}\)， \(\binom{0}{1}\mapsto\binom{b}{d}\)。 整个变换完全由这两根箭头的落点决定——矩阵不是一堆数字，它就是两根箭头。 后面的行列式、面积、体积，全部是从这两根箭头读出来的。

「仿射（affine）」这个名字来自仿射组合：形如 \(\sum_i \lambda_i p_i\) 且 \(\sum_i\lambda_i=1\) 的点组合。 仿射变换恰好就是"保持仿射组合"的变换，也就是"保持直线、平行、比例"的变换。

1.2 二维就四种基本动作

任何 \(2\times2\) 矩阵都能拆成下面这几样的组合。请特别注意最后一列——这四种动作对面积的影响差别极大，这正是后面所有内容的伏笔。

动作矩阵行列式面积几何描述
旋转 [cosθ, −sinθ; sinθ, cosθ] 1×1 只转，不拉不压。面积当然不变。
缩放 [a, 0; 0, b] ab×ab 横向拉 \(a\) 倍，纵向拉 \(b\) 倍。
剪切 [1, k; 0, 1] 1×1 形状被彻底扭曲，但面积纹丝不动。
反射 [−1, 0; 0, 1] −1×1 照镜子，面积不变但手性翻转（字母 b 变 d）。
退化 [1, 1; 1, 1] 0×0 整个平面被压到一条直线上，不可逆。
剪切这一行值得盯十秒

剪切把正方形推成很扁的平行四边形，形状丑到认不出来，但行列式老老实实等于 \(1\)。 这说明：行列式只数"面积/体积变了多少"，完全不关心"形状被扭曲成什么样"。

这个"冷漠"恰恰是天大的好事。概率密度换元时，我们只需要面积账目对得上，形状怎么歪都无所谓。 如果行列式还受形状影响，flow 的似然就没法算了。

动手拖一下：仿射变换实验台

1.3 加上平移，才叫"仿射"

线性变换有个讨厌的限制：原点必须固定。但现实中的变形常常还要整体搬家：

\[ \begin{aligned} x' &= a\,x + b\,y + e\\ y' &= c\,x + d\,y + f \end{aligned} \qquad\Longleftrightarrow\qquad x' = Jx + t,\quad t=\binom{e}{f} \]

几何上的分工极其清楚：

部分管什么对面积的影响
\(2\times2\) 矩阵 \(J\)形状：旋转、拉伸、剪切、翻转决定面积倍数
平移向量 \(t=(e,f)\)位置：整体挪动完全没有影响
请把这句话刻进脑子

平移不改变任何面积，所以对行列式毫无贡献。 这句话在后面会反复出现——比如 flow 的 coupling 层里那个平移项 \(t(z)\)， 在计算 log_det 时被整个忽略掉，理由就是这一条。

1.4 齐次坐标：把平移也塞进矩阵

为了让"连续做几个仿射变换"能写成"几个矩阵相乘"，工程上习惯多补一维：

\[ \begin{bmatrix}x'\\ y'\\ 1\end{bmatrix} =\underbrace{\begin{bmatrix}a&b&e\\ c&d&f\\ 0&0&1\end{bmatrix}}_{3\times3} \begin{bmatrix}x\\ y\\ 1\end{bmatrix} \]

这个 \(3\times3\) 矩阵的左上角 \(2\times2\) 块还是原来那个管形状的矩阵， 最右一列是平移，最后一行 \([0,0,1]\) 纯粹是为了凑成矩阵乘法的形式。

结论

不管你把维度补到多少、加了多少平移，真正决定体积变化的永远只有左上角那个方阵。 这就是为什么 flow 里可以随便加平移项而不用担心行列式——行列式只盯着那个方阵看。

1.5 仿射变换保住了什么、破坏了什么

保持不变会被改变
直线的"直"（直线还映射成直线）长度（会被拉长压短）
平行性（平行线还是平行线）角度（直角可以变成 \(60^\circ\)）
直线上的比例（中点还是中点）面积 / 体积（会被放大缩小一个固定倍数）
平行四边形还是平行四边形形状（正方形可以变成很扁的菱形）

请特别注意最后一行的对照："形状变得面目全非"和"体积变了多少"是两件完全独立的事。 剪切能让你认不出形状，但体积一点没变；等比缩放的形状和原来一模一样，但体积变了 \(a^2\) 倍。 行列式只负责后者。

1.6 复合的顺序很重要（矩阵乘法不可交换）

先旋转再剪切，和先剪切再旋转，结果完全不同。这不是数学上的怪癖，而是几何事实： 

// 先剪切 S 再旋转 R  vs  先旋转 R 再剪切 S
R·S = [0.71, 1.41; 0.71, 0.71]      S·R = [1.41, 0.71; 0.71, 0.71]
                             ↑ 明显不是同一个矩阵

但有一条性质是无论如何都成立的，而且它极其重要：

\[ \det(AB)=\det(A)\det(B) \]

几何含义：体积因子会沿着变换链连乘。先放大 3 倍再缩小 2 倍，净效果就是放大 1.5 倍，和顺序无关。 取对数之后，连乘变成连加：

\[ \log|\det(A_1A_2\cdots A_k)|=\sum_{i=1}^{k}\log|\det A_i| \]
这是 flow 能工程化的根

这条性质意味着：一百层变换叠起来，只需要把每层各自的 log_det 加起来就行， 不需要对复合后的整体求导、也不需要算整体矩阵。 flow 之所以能堆几十上百层还保持可训练，全靠这一条。

1.7 SVD：把任何线性变换拆成"旋转 → 拉伸 → 旋转"

这是理解 Jacobi 矩阵几何意义最有力的一把刀。任何矩阵都能分解成：

\[ J = U\,\Sigma\,V^{\!\top} \]

从右往左读（因为它作用在向量上是从右边先进去的）：

V⊤
旋转，把主方向对齐坐标轴
⟶
Σ
沿每个轴独立拉伸 σ₁, σ₂
⟶
U
旋转到最终朝向

任何局部线性变换 = 旋转 + 各向异性拉伸 + 旋转。 这就是 Jacobi 矩阵的完整解剖图。而且立刻得到两个结论：

  • 单位圆经过 \(J\) 之后变成椭圆，半轴长度就是奇异值 \(\sigma_1,\sigma_2\)；
  • \(|\det J|=\sigma_1\sigma_2\)——面积倍数就是所有奇异值的乘积。

第二条在高维下变得非常要命：\(n\) 维的 \(|\det J|\) 是 \(n\) 个奇异值相乘， 量级是 \(e^{O(n)}\)。\(n=256\) 时可能就是 \(10^{\pm80}\)—— 直接用浮点数存 det 必然溢出。这是 4.3 节要讲的"必须取对数"的第一个理由。

2行列式：它就是面积/体积倍数

2.1 单位正方形去哪儿了

线性变换 \(\begin{bmatrix}a&b\\c&d\end{bmatrix}\) 作用在两根基箭头上：

\[ \binom{1}{0}\mapsto\binom{a}{c}\ \text{（第一列）},\qquad \binom{0}{1}\mapsto\binom{b}{d}\ \text{（第二列）} \]

所以面积恰好为 1 的单位正方形，变成了由两根列向量张成的平行四边形： 

      (0,1)                                          (b,d)
       ●────────●                              ●───────────●
       │        │             J                ╱           ╱
       │        │      ───────────────►       ╱           ╱
       │        │                            ╱           ╱
       ●────────●                         ●───────────●
     (0,0)    (1,0)                   (0,0)        (a,c)

            面积 = 1                        面积 = |ad − bc|

关键一步：面积对每个自变量都是"线性"的。把其中一根箭头拉长 2 倍，平行四边形面积也正好翻倍。 正因为这个线性性，任意形状经过变换后，面积都统一乘以这个倍数——所以我们只需要盯住单位正方形就够了。

2.2 那个 ad − bc 到底怎么来的

两个箭头 \(u=(a,c)\)、\(v=(b,d)\) 张成的平行四边形，面积 = 底 × 高 = \(|u||v|\sin\theta\)。于是：

\[ \begin{aligned} \text{面积}^2 &= |u|^2|v|^2-(u\cdot v)^2 &&\text{（拉格朗日恒等式）}\\[2pt] &= (a^2+c^2)(b^2+d^2)-(ab+cd)^2\\[2pt] &= a^2b^2+a^2d^2+b^2c^2+c^2d^2-a^2b^2-2abcd-c^2d^2\\[2pt] &= a^2d^2+b^2c^2-2abcd\\[2pt] &= (ad-bc)^2 \end{aligned} \]

开根号就是 \(\text{面积}=|ad-bc|\)，正好是 \(|\det J|\)。 看出来了吗——那个看似莫名其妙的"交叉相乘相减"，本质上就是"底乘高"在坐标里的展开，不是什么神秘的公式。

2.3 三条一望即知的性质

不用记公式，画个平行四边形就能全部推出来：

  1. 两根箭头共线 ⟹ 面积为零 ⟹ \(\det=0\)。 平行四边形被压成一条线段。这就是"\(\det=0\) 等价于不可逆"的几何含义。
  2. 交换两根箭头 ⟹ 面积不变、方向翻转 ⟹ \(\det\) 变号。
  3. 把任意一根箭头拉长 \(\lambda\) 倍 ⟹ 面积翻 \(\lambda\) 倍 ⟹ \(\det\) 翻 \(\lambda\) 倍。

再补上 \(\det(I)=1\)（什么都不做，倍数就是 1）， 这四条唯一确定了行列式。数学家把这个叫"行列式的公理化定义"，但你完全可以把它当成几何常识。

2.4 符号 = 定向（手性）

公式里永远写 \(|\det J|\)，所以符号本身不影响概率。但它有明确的几何含义：

det 符号几何含义例子
det > 0保定向：右手系还是右手系旋转、缩放
det = 0退化：把空间压到了更低的维度投影、塌缩
det < 0反定向：手性翻转反射、镜像

概率质量分不清左右手，所以对概率来说 \(-2\) 和 \(+2\) 是一回事，都表示"面积放大 2 倍"。 但在需要定向一致性的场景（比如流形上微分形式的积分），符号就必须保留。

顺带一提，行列式和特征值的关系是：

\[ \det J=\prod_{i=1}^{n}\lambda_i,\qquad \operatorname{tr}J=\sum_{i=1}^{n}\lambda_i \]

在 flow 的语境里，这告诉你行列式是"所有方向上的伸缩倍数乘在一起"——有方向拉伸，有方向压缩，最终看的是乘积。

2.5 三角矩阵：行列式退化成对角线乘积

这一条是 flow 架构设计的唯一最重要动机。如果矩阵是三角形的：

\[ J=\begin{bmatrix}\lambda_1 & * & *\\ 0 & \lambda_2 & *\\ 0 & 0 & \lambda_3\end{bmatrix} \quad\Longrightarrow\quad \det J=\lambda_1\lambda_2\lambda_3 \]

为什么？因为上三角矩阵对应的平行四边形是一个"沿坐标轴摞起来的长方体被剪切过"的形状—— 剪切不改变体积（回想 1.2 节），所以体积就等于对角线撑起来的那个长方体的体积。

3Jacobi 矩阵：每个点各挂一个仿射变换

3.1 核心思想：非线性映射的逐点仿射化

整个第 3 章的主旨

非线性映射在每个点附近，看起来都像一个仿射变换；Jacobi 矩阵就是那个仿射变换的矩阵部分。

这就是泰勒展开的几何读法。对 \(f:\mathbb{R}^n\to\mathbb{R}^n\)，在点 \(z_0\) 附近：

\[ f(z_0+\delta)\;\approx\;\underbrace{f(z_0)}_{\text{平移项}}\;+\;\underbrace{J_f(z_0)}_{\text{矩阵项}}\,\delta \]

你看，这不就正好是 1.3 节的"平移 + 线性"的仿射形式吗？ \(f(z_0)\) 是平移，\(J\) 是那个 \(n\times n\) 矩阵。

Jacobi 矩阵的定义就是所有一阶偏导排成的矩阵：

\[ J_f(z)=\begin{bmatrix} \dfrac{\partial f_1}{\partial z_1} & \cdots & \dfrac{\partial f_1}{\partial z_n}\\[8pt] \vdots & \ddots & \vdots\\[8pt] \dfrac{\partial f_n}{\partial z_1} & \cdots & \dfrac{\partial f_n}{\partial z_n} \end{bmatrix} \]
所以 flow 到底是什么

flow 就是一个"每一点挂一个仿射变换"的变形，只不过这些仿射变换的参数不是手写的， 而是由一个神经网络根据当前坐标算出来的。

你堆 100 层，就是叠 100 次这样的"会看情况的仿射变形"。因为每一次都可逆、每一次都能算出体积倍数， 所以最后可以精确地反推出概率密度。

3.2 列向量 = 基箭头被送去的方向

和 1.1 节完全一样，只是现在每个点的两根箭头都不一样了。第 \(i\) 列 \(\partial f/\partial z_i\) 的含义是：

"在 \(z_0\) 处沿第 \(i\) 个坐标方向走一小步，在输出空间里体现成往哪个方向、走多远。"

在二维里，取 \(z_0\) 周围一个无穷小的单位正方形， 经过 \(f\) 之后（一阶近似下）变成一个无穷小的平行四边形，两条边就是 \(J\) 的两列。 这个平行四边形的面积，就是这一点的局部体积倍数 \(|\det J|\)。

3.3 圆变椭圆，以及"局部"到底有多局部

接着 1.7 节的 SVD：\(z_0\) 周围一个半径 \(r\) 的小圆， 映射后（一阶近似）变成一个椭圆，半轴是 \(\sigma_1 r\) 和 \(\sigma_2 r\)， 其中 \(\sigma_i\) 是 \(J_f(z_0)\) 的奇异值。

但注意那个"一阶近似"——它只在半径足够小的时候成立。半径一大，真正被映射出来的形状就会开始"歪"，不再是椭圆， 而是变得像香蕉或不规则的花瓣。这个偏差就是被丢掉的高阶项。

动手拖一下：看见"局部"两个字

3.4 极坐标：det 就是那个熟悉的 r

极坐标映射 \((x,y)=(r\cos\theta,\;r\sin\theta)\) 的 Jacobi 矩阵是：

\[ J=\begin{bmatrix}\cos\theta & -r\sin\theta\\ \sin\theta & r\cos\theta\end{bmatrix} \qquad \det J=r\cos^2\theta+r\sin^2\theta=\boxed{r} \]

这就是微积分里 \(dx\,dy=r\,dr\,d\theta\) 的那个 \(r\)。它的几何含义直白得不能再直白：

角度 \(\theta\) 转同样一小步 \(d\theta\)，半径越大，划出的弧长越长（弧长 \(=r\,d\theta\)）， 所以同一小块 \((dr,d\theta)\) 在平面上对应的实际面积正比于 \(r\)。

动手拖一下：同一个小方块，跑到外圈就变大了

3.5 链式法则 = Jacobi 矩阵相乘

如果 \(f=g\circ h\)，那么：

\[ J_f(z)=J_g\big(h(z)\big)\cdot J_h(z) \]

取行列式，配合 \(\det(AB)=\det A\det B\)：

\[ \det J_f=\det J_g\cdot\det J_h \quad\Longrightarrow\quad \log|\det J_f|=\log|\det J_g|+\log|\det J_h| \]
这解释了 flow 的一切工程细节
  • 为什么可以堆很多层：总的 log_det 就是各层 log_det 之和，互不干扰，可并行计算。
  • 为什么每层都要"便宜地算 det"：任何一层的 det 很贵，整个模型的训练成本就炸了。
  • 为什么用神经网络也成立：神经网络本身就是复合函数，链式法则照样适用，所以可以用反向传播自动求 \(J\)。

4概率密度换元：为什么非要有行列式

4.1 一维：从分布函数出发的严格推导

先看一维，因为一维能把所有细节摊开看。设 \(X=f(Z)\)，\(f\) 严格单调递增，\(Z\) 的密度是 \(p_Z\)。

从累积分布函数出发：

\[ F_X(x)=P(X\le x)=P\big(f(Z)\le x\big)=P\big(Z\le f^{-1}(x)\big)=F_Z\big(f^{-1}(x)\big) \]

两边对 \(x\) 求导，用链式法则：

\[ p_X(x)=p_Z\big(f^{-1}(x)\big)\cdot\big(f^{-1}\big)'(x) =\frac{p_Z\big(f^{-1}(x)\big)}{f'\big(f^{-1}(x)\big)} \]

因为 \((f^{-1})'(x)=1/f'(f^{-1}(x))\)。写成更对称的形式（令 \(z=f^{-1}(x)\)，则 \(x=f(z)\)）：

\[ p_X\big(f(z)\big)=\frac{p_Z(z)}{|f'(z)|} \qquad\text{等价于}\qquad \boxed{\,p_X(x)=p_Z(z)\,\bigl|\det J_{f^{-1}}(x)\bigr|\,} \]
用人话读一遍

"同样一堆概率质量，在新的坐标里被摊到了多少倍大的地方？摊得多大，密度就除以多大。"

就像橡皮膜上撒满细沙：膜拉长 2 倍，那一块面积变成 2 倍，沙子密度就减半—— 沙粒总数（概率质量）一颗都没变。

一维最小的例子，自己动手验一下：

映射 x = 2z   ⟹   J = [2]，det = 2

z 空间:  ├────┤                  长度 1，密度 1
         0    1

                 ↓  ×2

x 空间:  ├──────────┤            长度 2，密度 1/2
         0          2

验证：p_X = p_Z · |1/2| = 1/2，总质量 = 1/2 × 2 = 1  ✓

4.2 高维：同一件事，只是每一点的比例不同

高维的换元公式完全一样，只是 \(f'\) 换成了 \(\det J\)：

\[ p_X(x)=p_Z\big(f^{-1}(x)\big)\cdot\bigl|\det J_{f^{-1}}(x)\bigr| \]

它的推导完全平行：取 \(Z\) 空间里一小块区域 \(A\)，被送到 \(f(A)\)。 变换只是搬东西，不产生也不销毁概率质量：

\[ \int_A p_Z(z)\,dz=\int_{f(A)}p_X(x)\,dx \]

而微元之间的关系是 \(dx=|\det J_f(z)|\,dz\)（这是 Jacobi 行列式的定义性含义）。 让 \(A\) 收缩到一个点，就得到上面的公式。

动手拖一下：一维换元，看见"拉伸 → 密度降低"

4.3 为什么工程上一律用 log|det| 而不是 det

理由说明
数值不溢出 高维下 \(|\det J|=\prod_i\sigma_i\)，量级 \(e^{O(n)}\)。 图像模型 \(n\sim10^5\) 时，直接存 det 必然是 inf 或 0。 取对数后 \(\sum_i\log\sigma_i\) 只是 \(O(n)\)，很温和。
梯度更稳 乘积的梯度是 \(n\) 项求和，累加误差是指数级的。对数的梯度只是和式的梯度。
和似然天然衔接 训练目标本来就是对数似然，加一个 log_det 直接相加即可，不需要 exp 来回折腾。
多层的加法 \(\log|\det(AB)|=\log|\det A|+\log|\det B|\)，100 层就是 100 个数相加，简单又稳定。
工程惯例

所有 flow 实现里，每一层的接口返回的都是 log_det，从来不是 det。 你在 PyTorch 或 JAX 的 flow 库里看到的 forward() → (z, log_det) 就是这个原因。 如果哪天你看到有人返回 det，那多半是个 bug。

5放进 Flow 模型：它到底承担了什么

5.1 形式定义

一个 normalizing flow 是一个可逆且可微的映射 \(f:\mathbb{R}^n\to\mathbb{R}^n\)，把简单的潜变量分布搬运成复杂的数据分布：

\[ z\sim p_Z \quad\Longrightarrow\quad x=f(z)\sim p_X \qquad\text{其中}\qquad p_Z=\mathcal{N}(0,I)\ \text{（通常）} \]

三个硬性要求（"normalizing" 这个词的来源就是要让 \(p_X\) 真正归一化）：

  1. 双射：\(f\) 必须是可逆的，每个 \(x\) 对应唯一一个 \(z\)。所以 \(\det J\ne0\) 处处成立。
  2. 可微：两边都得能求导，这样才能用梯度下降训练，也才有反函数定理。
  3. log_det 可高效计算：这是工程上的真正约束，直接决定了所有架构设计。

5.2 训练目标

把换元公式代入，得到 flow 的似然：

\[ \log p_X(x)=\log p_Z\big(f^{-1}(x)\big)+\log\bigl|\det J_{f^{-1}}(x)\bigr| \]

实践中更常用正向写法（因为生成方向算得更顺）：令 \(z=f^{-1}(x)\)，则

\[ \boxed{\ \log p_X(x)=\underbrace{\log p_Z(z)}_{\text{潜空间里的"基础似然"}}+\underbrace{\log\bigl|\det J_f(z)\bigr|}_{\text{体积修正项}}\ } \]

训练就是最大化 \(\mathbb{E}_{x\sim\mathcal{D}}\big[\log p_X(x)\big]\)。这一项的物理含义很漂亮：

  • 第一项问："这个数据点反推回潜空间后，在标准高斯看来有多正常？"
  • 第二项问："为了把它送到那儿，空间被拉伸/压缩了多少？"

没有第二项，这个"概率"根本不是概率——它不对任何区域积分为 1，只是一个无意义的打分函数。

5.3 关键问题：去掉 log|det| 会发生什么

这是理解行列式在优化中作用的核心问题，值得单独一节。用一个干净的例子说清楚。

设定：一维，基础分布取 \(p_Z=\mathrm{Uniform}[0,1]\)（即 \(p_Z\equiv1\) 在 \([0,1]\) 上，其余为 \(0\)）。变换取仿射 \(x=\sigma z+\mu\)。

正确的目标（带 log|det|）：

\[ \log p_X(x)=\underbrace{\log 1}_{p_Z}+\log\frac{1}{\sigma}=-\log\sigma \qquad(x\in[\mu,\mu+\sigma]) \]

要让所有数据都落在支撑集里，必须有 \(\sigma\ge\text{data 的范围}\)。 而 \(-\log\sigma\) 是关于 \(\sigma\) 的递减函数，所以最优解就是把 \(\sigma\) 取成恰好能装下数据的最小值。 换句话说：行列式项精确地告诉模型"你的映射该铺多大"。

去掉 log|det| 的目标：

\[ \widetilde{\log p_X}(x)=\log p_Z\big(f^{-1}(x)\big)=\begin{cases}0,& z\in[0,1]\\-\infty,&\text{否则}\end{cases} \]

这个目标函数有两个致命问题：

问题一：对"铺多大"完全没有约束

只要能把数据全都塞进 \([0,1]\)，得分就是 \(0\)——而满足这个条件的是一个无穷大的解族： \(\sigma\) 可以取 \(0.8\)，也可以取 \(10^6\)。 目标函数对这些解一视同仁，完全没有信息量。梯度会说"随便，都行"。

问题二：它根本不是概率密度

这个打分函数不满足 \(\int p=1\)。归一化因子 \(1/\sigma\) 被丢掉了， 而它正是让密度积分为 1 的那一项。优化一个未归一化的打分函数，得到的"似然"没有任何统计意义， 也没法用来做模型比较、异常检测、或算互信息。

正确的理解

\(\log|\det J|\) 就是归一化因子本身。 它同时扮演两个角色：让密度积分为 1（数学上），以及约束映射该铺多大（优化上）。 这两个角色其实是同一件事的两面——它就是在替"体积"记账。

用高斯基础分布时结论完全一样：去掉行列式项后，模型会倾向于把映射无限拉大， 让所有数据点都落到 \(p_Z\) 的峰值附近，从而得到一个 完全不看数据、退化成"常数函数"的解。\(-\log\sigma\) 这一项正是拦住它的那道墙。

把 coupling 层拆开看：这就是亲手的仿射变换

RealNVP 的一层长这样（把 \(z\) 按维度切成两半）：

x_A = z_A                          ← 前一半原样传过去（这是"三角"的来源）
x_B = exp(s(z_A)) ⊙ z_B + t(z_A)   ← 这就是一个仿射变换！
      └── 缩放 ──┘   └ 平移 ┘
      s 和 t 由神经网络算出

它的 Jacobi 矩阵是分块三角的：

\[ J=\begin{bmatrix} I & 0\\[4pt] \dfrac{\partial x_B}{\partial z_A} & \operatorname{diag}\!\big(e^{s(z_A)}\big) \end{bmatrix} \qquad\Longrightarrow\qquad \det J=\prod_i e^{s_i(z_A)} \]
三个要点，逐个对上前面讲的东西
  • 左上角的 \(I\) 是因为前一半没动，恒等映射，\(\det I=1\)。
  • 左下角那一块稠密且很贵（需要算 \(\partial s/\partial z_A\)）， 但三角矩阵的行列式只取对角线，所以我们根本不需要算它——这正是三角结构省下来的全部成本。
  • 平移项 \(t(z_A)\) 完全消失。 回想 1.3 节那句话：平移不改变任何体积。这就是它在公式里消失的原因。

最终：

\[ \log|\det J|=\sum_i s_i(z_A) \qquad\text{——一个纯加法，}O(n)\text{ 搞定} \]
所以整件事的因果关系是这样的

不是"碰巧用了仿射层"，而是为了 log_det 算得起，被迫把每层都做成仿射的。 如果每层都是稠密矩阵，光算行列式就要 \(O(n^3)\)，在几万维的图像上根本跑不动。 log_det 的计算复杂度，是 flow 架构设计的头号约束。

5.5 连续流：行列式换成迹

Neural ODE / Continuous Normalizing Flow 把离散的层换成连续时间演化：

\[ \frac{dz(t)}{dt}=v\big(z(t),t\big),\qquad z(0)=z,\qquad x=z(T) \]

此时 \(J(t)=\partial z(t)/\partial z(0)\) 满足 \(\dot J=(\partial v/\partial z)J\)，取对数求导得到 Liouville 方程：

\[ \frac{d}{dt}\log\bigl|\det J(t)\bigr|=\operatorname{tr}\!\left(\frac{\partial v}{\partial z}\right)=\nabla\cdot v \]
几何读法（非常美）
  • 行列式 = 有限时间累积起来的体积倍数；
  • 散度（速度场 Jacobi 的迹） = 局部体积的瞬时相对变化率；
  • 两者是积分与指数的关系：\(\log|\det J(T)|=\int_0^T\nabla\cdot v\,dt\)。

直观图像：速度场像水流，某点水流"向外发散"（\(\nabla\cdot v>0\)）就说明那里的小流体元正在膨胀，体积在涨； "汇聚"则体积在缩。

这个恒等式带来两个巨大的实用好处：

  1. 从 \(O(n^3)\) 降到 \(O(n)\)：不需要算行列式，只需要算迹。这是 FFJORD 这类方法能上高维的根基。
  2. 无散场直接给出保体积 flow：\(\nabla\cdot v\equiv0\) 意味着 \(\log|\det|\equiv0\)， 也就是映射处处保体积。哈密顿流就是这么一类，物理上对应"不可压缩流体"。

高维下算 \(\operatorname{tr}(\partial v/\partial z)\) 仍然需要 \(n\) 次反向传播，所以实践中用 Hutchinson 估计量做无偏随机估计：

\[ \operatorname{tr}(A)=\mathbb{E}_{\epsilon}\bigl[\epsilon^{\!\top}A\epsilon\bigr],\qquad \epsilon\sim\mathcal{N}(0,I)\ \text{或 Rademacher} \]

一次采样 + 一次向量-Jacobian 积就能得到迹的无偏估计，成本降到 \(O(1)\) 次反向传播。

5.6 陷阱清单：几何上的硬约束

陷阱几何原因后果 / 对策
tanh / sigmoid 尾巴 把无穷长的尾巴压进有限区间，局部体积压缩比 \(\to\infty\) \(\log|\det|\to-\infty\)，数值溢出；且无法建模重尾。改用仿射 coupling 或 spline。
\(\det J\to0\) 某个方向上的伸缩倍数 \(\sigma_i\to0\)，局部把体积压没了 局部不可逆，逆映射的 Jacobi 发散。\(s\) 要加约束（如 tanh 限幅），初始化别太激进。

拓扑不能变 微分同胚保持拓扑：连通分支数、有界/无界性、亏格都不变 单峰基础分布无法一步变成"中间完全为零的双峰"。只能靠多层非线性慢慢揉，或换基础分布。

一句话总结陷阱

这些都不是"实现 bug"，而是几何上的硬约束。 你不可能把无限长的尾巴塞进有限区间还不产生无限大的体积压缩比—— 行列式只是在忠实地报告这个事实。当 log_det 爆炸时，模型不是在犯错误，而是在告诉你： 你让它做的这件事，几何上就不可能。

6速查与总结

6.1 常见误解澄清

误解纠正
"行列式就是矩阵算出来的一个数" 它是几何量：单位正方形/立方体被映射后的体积。公式只是这个几何量的坐标表达。
"det 能反映变换有多复杂/多扭曲" 不能。剪切可以把形状扭曲到认不出来而 \(\det=1\)。det 只数体积，不数形状。
"Jacobi 矩阵就是偏导数表格" 它是一份局部仿射近似。行列是基箭头的去向，SVD 给出"旋转-拉伸-旋转"的解剖。
"采样和评分一样贵" 完全不对称。采样只要前向 \(x=f(z)\)，一次都不算 det；评分才需要 log_det。
"flow 用仿射层只是因为它简单" 是因为三角 Jacobi 让 log_det 降到 \(O(n)\)。稠密矩阵的 det 是 \(O(n^3)\)，高维下不可行。
"\(\log|\det|\) 只是个修正项，可有可无" 它是归一化因子本身。去掉它，目标函数就不再对应任何合法的概率密度。
"det 的负号表示概率是负的" 负号只表示定向翻转（手性）。概率公式里一律取绝对值。
"平移也会影响 det" 不会。平移不改变任何体积，这也是 coupling 层里的 \(t(z)\) 在 log_det 里彻底消失的原因。

6.2 一页速查

概念几何含义在 flow 里的角色
仿射变换 线性（旋转/拉伸/剪切/翻转）+ 平移 最小的可逆变形单元
Jacobi 矩阵 \(J\) 局部线性化；列 = 基箭头的去向；单位球 → 半轴为奇异值的椭球 决定"形状怎么变"
\(\det J\) 局部体积倍数（符号表定向） 决定"体积怎么变"
\(\log|\det J|\) 体积倍数的对数；高维下避免 \(e^{O(n)}\) 溢出 似然里的体积修正项 + 归一化因子
三角 Jacobi 剪切不改变体积，所以体积 = 对角线撑起的方体 让 log_det 从 \(O(n^3)\) 降到 \(O(n)\)
散度 \(\nabla\cdot v\) 局部体积的瞬时相对变化率 连续 flow 里 log_det 的替代品，\(O(n)\)
\(\det J=0\) 局部塌缩，平行四边形被压扁成线 硬禁区：不可逆，逆映射发散
最后的最后

Jacobi 矩阵负责"形状怎么变"，行列式负责"体积怎么变"；前者决定这个变换长什么样，后者决定概率密度必须按什么比例补偿回去。

而 flow 的全部架构设计，本质上就是在"表达力足够强的可逆映射"和"log_det 算得起"之间找平衡。 你以后每看到一个 flow 的新变体，都可以问同一个问题：它的 Jacobi 矩阵长什么结构？log_det 怎么算？ 这两个问题的答案，几乎就决定了这个架构的全部特性。

7六个家族：各自怎么算 log_det

第 5 章给了你一张架构对比表，但那是目录。这一章把每个家族拆开，看它们的 Jacobi 矩阵到底长什么结构、 log_det 具体怎么算，以及各自牺牲了什么、换来了什么。

带着这个问题读

每看到一个家族，问同一句话：它是怎么造出"便宜的可逆结构"的？ 你会发现所有设计都在回答这一个问题。

7.1 Coupling 家族：NICE → RealNVP → Glow

NICE (2014)：加性耦合，一个意外的礼物

最朴素的 coupling 层把 \(z\) 切成两半，一半原样传过去，另一半只做平移：

\[ \begin{aligned} x_A &= z_A\\ x_B &= z_B + t(z_A) \end{aligned} \]

它的 Jacobi 矩阵是分块三角的：

\[ J=\begin{bmatrix} I & 0\\ \dfrac{\partial t}{\partial z_A} & I \end{bmatrix} \]

对角线由两个单位块组成，所以：

\[ \det J = 1 \qquad\Longrightarrow\qquad \log|\det J|\equiv 0 \]
几何读法

加性耦合 = 只做剪切。回想第 1 章那句话——剪切把正方形推成很扁的平行四边形，而面积纹丝不动。 NICE 的每一层都在"扭形状"，但从不"改体积"。这就是 \(\det J\equiv1\) 的全部含义。

这个性质是双面的：

  • 好处：数值绝对稳定。log-det 恒等于 0，永远不会溢出、不会爆炸，训练起来毫无顾虑。
  • 坏处：表达力受限。不能改变体积，就意味着无法把"集中的高斯"摊成"弥散的数据分布"——而生成模型的核心任务恰恰就是这个。

所以 NICE 必须在最后加一个固定的对角缩放层来引入体积变化。 整个模型里唯一改变体积的就是那个简单的缩放，中间所有 coupling 层都只管扭形状。这是一个相当强的结构性妥协。

RealNVP (2016)：把平移升级成仿射

\[ \begin{aligned} x_A &= z_A\\ x_B &= \exp\!\big(s(z_A)\big)\odot z_B + t(z_A) \end{aligned} \qquad\Longrightarrow\qquad \log|\det J|=\sum_i s_i(z_A) \]

公式在第 5.4 节见过。这里补充两个实现细节，它们都是业界标准做法，值得单独理解。

细节一：为什么是 exp(s)，而不是直接输出缩放系数？

因为 \(\exp\) 保证输出恒正，从而保证对角线元素非零、\(\det J\ne0\)、映射可逆。 这是把"可逆性"这个约束编码进架构里的标准手法——你不需要在训练时加惩罚项去逼模型保持可逆， 架构本身在数学上就不可能产生不可逆的参数。类似的技巧还有用 \(\tanh\) 限幅、用 softplus 保证正数。

细节二：s 和 t 可以是任意复杂的函数

它们可以是 ResNet，可以是 Transformer，层数随便加，完全不影响 log-det 的计算。

为什么？因为在 Jacobi 矩阵里，\(s\) 和 \(t\) 只出现在"被零块挡住"的位置。log-det 只依赖 \(s\) 的输出值，完全不依赖 \(s\) 的导数结构或内部复杂度。 这是 coupling 最优雅的地方——表达力和 log-det 成本彻底解耦。你把 \(s\) 换成一百层的网络，log-det 依然只是 \(\sum_i s_i\)。

Glow (2018)：补上通道混合

RealNVP 有个结构性问题。"切成两半、一半不动"确实造出了三角结构，但代价是通道之间没有真正混合—— 信息只能在层与层之间缓慢渗透，深度的利用效率很低。

Glow 的解法是在 coupling 层之间插入 1×1 可逆卷积：

\[ x = Wz \quad\text{（}W\text{ 是 }C\times C\text{ 矩阵，在所有空间位置上共享）} \qquad\Longrightarrow\qquad \log|\det| = H\cdot W\cdot\log|\det W| \]

三个工程要点：

  • 它是稠密矩阵，但很小。只有 \(C\times C\)（通道数，通常 256~512）， \(O(C^3)\) 完全能忍——这是"\(C\times C\) 小稠密"那一行的实际用法。
  • 用 LU 分解算 \(\log|\det W|\)。直接算行列式在高维下数值不稳， 分解成下三角乘上三角后取对角线对数求和，稳定得多。这也是为什么 \(W\) 的参数化通常存的是 LU 因子而非 \(W\) 本身。
  • 初始化为随机正交矩阵。此时 \(|\det W|=1\)、\(\log|\det W|=0\)， 训练起点不会给似然带来任何意外偏移。

Glow 的另一个贡献是 ActNorm：一个"数据依赖的初始化"——用第一个 batch 的均值方差去初始化每个通道的缩放和平移。 相当于在训练开始前先把数据白化一遍，让后续层不必花力气去适应尺度。

三种"混合"机制的对比

到这里可以看清 flow 里"让维度互相影响"的三种手段：

机制谁影响谁J 结构\(\log|\det|\)代表
Coupling B 的每一维受整个 A 影响 分块三角 \(\sum_i s_i(z_A)\) NICE, RealNVP
Autoregressive 第 i 维受前面所有维影响 三角 \(\sum_i s_i(z_{<i})\) MAF, IAF
1×1 卷积 全部通道，所有空间位置同步 稠密但小 \(H\cdot W\cdot\log|\det W|\) Glow

注意最后一行：coupling 和 autoregressive 都只是"部分混合"，只有 1×1 卷积是"全通道混合"。 所以 Glow 的实际配置是两者交替——coupling 层负责非线性形变，1×1 卷积负责混通道，各司其职。

7.2 Autoregressive 家族：MAF 与 IAF 的对偶

MAF（Masked Autoregressive Flow）的公式看起来和 affine coupling 几乎一样：

\[ x_i = \exp\!\big(s_i(z_{<i})\big)\cdot z_i + t_i(z_{<i}) \]

只是"依赖前面所有维"代替了"依赖另一半"。Jacobi 依然是三角的， \(\log|\det|=\sum_i s_i(z_{<i})\)。

IAF（Inverse Autoregressive Flow）用的是完全相同的公式——只是把 \(x\) 和 \(z\) 的角色互换。

这个对偶性是 flow 里最实用的一条工程知识，值得停下来看清楚：

前向 \(z\to x\)（采样）反向 \(x\to z\)（密度评估）
MAF需 n 次串行（慢）一次并行（快）
IAF一次并行（快）需 n 次串行（慢）

为什么会这样？

在 MAF 里，\(s_i,t_i\) 依赖 \(z_{<i}\)。 从 \(z\) 出发时，所有 \(z_{<i}\) 都已知，可以一次并行算出全部 \(s,t\)，然后直接得到 \(x\)； 但反过来要从 \(x\) 求 \(z\)，就必须逐维递推——因为 \(z_i\) 依赖 \(z_{<i}\)，而 \(z_{<i}\) 又得先由 \(x_{<i}\) 反解出来。串行性是被依赖结构直接决定的。

IAF 把方向反过来，优势也就跟着反过来。

一条会反复用到的取舍

训练需要密度评估（要快），采样需要前向（要快），两者不可兼得。

  • 你要似然（密度估计、异常检测、精确概率比较）→ 用 MAF，训练快。
  • 你要快速采样（变分推断里的 posterior、实时生成）→ 用 IAF， 代价是训练时只能用"反向 KL"这类不需要精确似然的目标函数。

7.3 低秩结构：Planar / Radial / Sylvester

前面两个家族都在"造三角"。还有一类完全不同的思路：在单位阵上加一个低秩扰动。

Planar flow

\[ x = z + u\cdot h(w^{\!\top}z+b) \qquad\Longrightarrow\qquad J = I + u\,h'(w^{\!\top}z+b)\,w^{\!\top} \]

也就是单位阵加上一个秩一矩阵。用矩阵行列式引理 \(\det(I+uv^{\!\top})=1+v^{\!\top}u\)：

\[ \det J = 1 + u^{\!\top}h'(w^{\!\top}z+b)\,w \qquad\Longrightarrow\qquad \log|\det J|=\log\bigl|1+u^{\!\top}h'w\bigr| \]
几何读法

秩一扰动只在"一个方向"上拉伸或压缩空间，其余所有方向原封不动。 想象把整个空间沿着某根轴推一把——垂直于那根轴的方向完全不受影响。 这也解释了它的局限：只改一个方向，能做的事非常有限。

Radial flow

\[ x = z + \beta\,h(\alpha,r)\,(z-z_0),\qquad r=|z-z_0| \]

沿半径方向扰动，以 \(z_0\) 为中心的球对称变形。 \(\det J\) 有闭式解，形如 \((1+\beta h)^{n-1}(1+\beta h+\beta h' r)\)——前一个因子来自"垂直方向不变的那 \(n-1\) 维"， 后一个来自"径向被改变的那 1 维"。这个结构本身就是"1 个方向特殊 + n−1 个方向相同"的直接体现。

这两类的定位要摆正

单层表达力很弱（秩一扰动改不了多少东西），做生成模型的主力是不够的。 它们的真正用武之地是变分推断里的 posterior 近似——把一个简单的对角高斯近似后验， 用几层 planar/radial 揉成更贴近真实后验的形状。之所以够用，是因为 posterior 通常维度不高、形状不复杂， 几层就足以带来明显改善。在 flow 的原始论文里，planar/radial 本来就是为变分推断提出的，而不是为生成建模。

Sylvester flow 是自然推广：用秩-\(k\) 扰动代替秩一：

\[ x = z + U\,h(V^{\!\top}z+b) \]

\(k\) 可调，在表达力和成本之间插值；\(k\) 取满就退化成一般的线性层。 这是"低秩"这一支里唯一能拿来做正经生成模型的成员。

7.4 单调样条：突破"仿射"的天花板

现在指出前面所有家族的一个共同天花板。

仿射层的硬限制

在 coupling 层里，\(x_B\) 的每一维只是 \(z_B\) 对应维的线性变换（缩放 + 平移）， 缩放系数由 \(z_A\) 决定。网络再深，单层内部这种"线性"是死的。 仿射层能表达的形变，本质上只有"整体拉伸"。

怎么突破？——造一个单调函数来代替仿射。

单调神经网络（Unconstrained Monotonic NN）

构造非常漂亮：不直接造单调函数，而是造一个恒正的导数，然后积分。

\[ y = f(x) = b + \int_0^x g(t)\,dt,\qquad g(t)>0 \]

\(g\) 用一个恒正的网络表示（比如输出过 softplus），积分用数值积分。 因为导数恒正，\(f\) 必然单调，可逆性自动成立。 而 \(\log|\det|=\log g(x)\)——连数值积分都不用做，只要算被积函数在某一点的值。

RQ-NSF（Rational-Quadratic Neural Spline Flow, 2019）

这是目前最实用的方案：

  • 把定义域切成 \(K\) 个区间，每个区间上放一个单调有理二次函数（分子分母都是二次多项式）。
  • 有理二次能表达"先快、后慢、再快"这类形状，比仿射强得多——二次的分子分母各有一个弯曲自由度，组合起来很灵活。
  • 参数由 autoregressive 网络输出：每个区间的边界位置 + 每个边界处的导数（导数严格为正，单调性由此保证）。
  • \(\log|\det|=\sum\log(\text{每一点的导数})\)，仍然是 \(O(n)\)。
几何读法

仿射是"整体拉伸"，样条是"每一段各拉伸多少"。 就像用分段函数去逼近任意曲线——只不过为了保证可逆，用的必须是单调的分段有理二次。 这把"一个缩放系数管整个领域"升级成了"每个区间各自一个缩放规律"，表达力的提升是量级上的。

代价是实现复杂一些（要定位落在哪个区间、求有理二次在该点的导数），但依然是 \(O(n)\)。现在做表格数据的密度估计，NSF 通常是首选—— 在那一类任务上它长期占据 SOTA，而且理论性质干净（精确似然、精确采样）。

7.5 残差流：把 ResNet 变成可逆的

coupling 和 autoregressive 都要"把维度切开"，在设计上很不自由。残差流想直接复用现成的 ResNet：

\[ x = z + g(z) \]

逆映射是 \(z = x - g(z)\)，用不动点迭代求解。

可逆的充分条件

\(g\) 的 Lipschitz 常数 \(\mathrm{Lip}(g)<1\)。 此时映射是压缩的，不动点存在且唯一，迭代必然收敛。 几何上：\(g\) 把任意两点的距离缩短，所以 \(z\mapsto z+g(z)\) 不会把两个不同的点合并到一起。

log-det 怎么算？没有三角结构可用，改用幂级数：

\[ \log\det(I+J_g)=\sum_{k=1}^{\infty}(-1)^{k+1}\frac{\operatorname{tr}(J_g^k)}{k} \]

然后用 Hutchinson 估计每一项的迹，并截断到前几项—— \(\mathrm{Lip}(g)<1\) 保证级数收敛，而且高阶项自动变小，所以截断误差可控。

为什么值得做：残差结构可以直接套用图像领域成熟的 ResNet 架构，不必像 coupling 那样把通道切成两半、破坏网络设计的自由度。 i-ResNet 的做法是用谱归一化把每一层的 Lipschitz 常数压在 1 以下，从而在整个网络上满足可逆条件。

代价：log-det 是估计值（截断引入偏差、随机估计引入方差），求逆的不动点迭代也慢。 所以它属于"架构自由度"换"数值精度"的交易。

7.6 连续流：CNF / FFJORD 的工程细节

第 5.5 节讲了 Liouville 方程，这里补工程侧。

训练：内存优势

连续流有一个离散流没有的好处——不需要保存中间激活。 用 Neural ODE 的 adjoint 方法反向传播，内存是 \(O(1)\)。 而离散 flow 有几十上百层，训练时所有层的激活都得存着——这是离散 flow 在图像尺度上很吃内存的原因之一。

trace 估计

FFJORD 用 Hutchinson 恒等式：

\[ \operatorname{tr}(A)=\mathbb{E}_{\epsilon}\bigl[\epsilon^{\!\top}A\,\epsilon\bigr],\qquad \epsilon\sim\mathcal{N}(0,I)\ \text{或 Rademacher} \]

一次采样加一次向量-Jacobian 积就够，完全不用构造完整的 Jacobi 矩阵—— 这是它能把 \(O(n^3)\) 降到 \(O(n)\) 的机制所在。

优势与劣势

优势劣势
不需要架构约束——速度场 \(v\) 可以是任意神经网络，不用切维度、不用造三角结构 解 ODE 慢——采样要几十到几百步，每步都要算一次网络
天然保体积——只要让 \(v\) 无散（比如用流函数构造），\(\log|\det|\equiv0\) 刚性（stiffness）问题——轨迹曲率大时需要自适应步长求解器，否则误差失控
表达力随积分时间增长——"深度"不是超参数，而是积分时长 trace 是随机估计——有方差，训练不如离散流稳

FFJORD 的实用改进是用一个正则项让轨迹变直，从而减少求解步数。 这个"把轨迹拉直"的思路，在第 8.3 节会看到它的极端版本——变成一整个方法族的核心思想。

7.8 可逆性到底贵在哪

流模型没有像 GAN / diffusion 那样主导生成领域，原因值得直说，不要绕着讲：

四条约束
  1. 维度必须相等。\(n\to n\)，不能降维。参数量和计算量比 VAE / GAN 大得多， 而生成质量又受限于"必须精确可逆"这个自我约束。
  2. 拓扑不能变。微分同胚保持连通分支数、有界性。单峰基础分布无法一步变成"中间完全为零的双峰"。
  3. log-det 的数值问题。高维下它是 \(n\) 项之和、量级 \(O(n)\)， 方差和稳定性都要小心处理。
  4. 采样可能必须串行。自回归类不能并行；连续流要解 ODE。

这四条里，只有第一条和第二条是"硬"的（数学上的必然），后两条是工程问题。

而第 8 章会看到：整个生成模型领域的演进，很大程度上就是在绕开第一条和第三条。 这是一个非常清晰的视角——后面所有的"新方法"，你都可以问它：你绕开的是哪一条？

8统一视角：所有生成模型都在记账

这一章是全篇的收尾，也是最有意思的部分。我们会把 flow、VAE、GAN、diffusion 放在同一把尺子上， 然后看到它们其实在解同一道题——只是记账方式不同。

8.1 所有生成模型都在做同一件事

换个角度重新看这个领域。所有生成模型的共同骨架是：

共同骨架

从一个简单分布出发，通过某个映射把概率质量搬到数据分布上，并在体积改变时记账。

差别只在怎么记账：

模型映射怎么记账后果
Flow 确定性可逆双射 精确记账：\(\log|\det J|\) 精确似然；可逆性约束强
VAE 随机编码 + 随机解码 近似记账：用变分后验近似逆映射 只能得到 ELBO 下界
GAN 确定性映射 \(G(z)\)，但不可逆 不记账 无似然，但也没有约束
Diffusion / FM 加噪过程 + 反向去噪 用回归绕开记账 训练不需要算 log-det

VAE 那一行值得展开

VAE 优化的目标是：

\[ \log p(x)\;\ge\;\underbrace{\mathbb{E}_{q(z|x)}\bigl[\log p(x|z)\bigr]}_{\text{重构项}}\;-\;\underbrace{\mathrm{KL}\bigl(q(z|x)\,\|\,p(z)\bigr)}_{\text{KL 项}} \]

第二项 KL 在做什么？

它就是在补偿"缺失的体积账"

因为 VAE 的映射是随机的、不可逆的，你不知道从 \(z\) 到 \(x\) 的真实 \(\log|\det J|\) 是多少，只能用变分后验 \(q(z|x)\) 去近似它。 当 \(q\) 完美匹配真实后验时，这个下界取等号；否则就是严格的下界。

Flow 之所以能拿到等式而不是下界，正是因为它精确地知道自己的体积变化。 这就是"可逆 + 精确 log-det"换来的那个"等于号"的价值。

GAN 那一行

判别器完全没有"体积"概念，它只判断"像不像"。所以 GAN 不受可逆性、拓扑、维度相等的约束—— 它可以任意降维、任意扭曲、任意跳变。样本因此可以很锐利，代价是训练不稳、没有似然、容易模式崩塌。

这就是"记账"视角的威力

它把三个看起来完全不同的模型族放在同一把尺子上： 你能精确记账吗？能，就是 flow；不能但愿意近似，就是 VAE；不想记，就是 GAN。

8.2 连续流的统一：概率流 ODE

这是全篇最重要的一个统一。

考虑任意一个扩散过程（SDE）：

\[ dx = f(x,t)\,dt + g(t)\,dw \]

它都有一个确定性的"概率流 ODE"，其边缘分布与这个 SDE 完全相同：

\[ \frac{dx}{dt} = f(x,t) - \tfrac{1}{2}g(t)^2\,\nabla_x\log p_t(x) \]

右边第二项里的 \(\nabla\log p_t(x)\) 就是 score（分数函数，对数密度的梯度）。

这一行式子做的事

它直接把 diffusion 纳入了 flow 的框架：diffusion 的采样过程本质上就是一个 CNF， 它的速度场由 score 决定。于是得到一个惊人的结论：

CNF / FFJORD 和 diffusion 是同一件事的两种参数化方式——都在学一个从噪声到数据的时间相关速度场。

那它们的区别在哪？在怎么训练。

FFJORD / CNFDiffusion
速度场 直接参数化 \(v_\theta\) 由 score 决定：\(v=f-\tfrac12 g^2\nabla\log p_t\)
训练目标 最大似然 → 必须算 \(\operatorname{tr}(\partial v/\partial z)\) Score matching → 回归加噪过程，完全不用算 trace
数值性质 trace 是随机估计，方差大、训练不稳 回归目标噪声小，训练稳定
这解释了为什么 diffusion 大获成功而 FFJORD 没有

两者在数学上是同一族模型，但 diffusion 用一个巧妙的等价性，把"最难算的 log-det"换成了一个普通的回归问题：

训练时不去算 \(\nabla\log p_t\)，而是去预测"我往这张图里加了多少噪声"—— 这个预测任务在数学上等价于知道了 score。难算的量被一个容易的监督信号替代了。

用几何语言再说一遍：

FFJORD 直接学"速度场长什么样"，所以训练时必须盯着速度场的散度（也就是体积变化率）。 Diffusion 学的是"分数场"，而分数场可以从加噪过程免费回归出来。 体积的账仍然在记（由概率流 ODE 保证边缘分布正确），但记账的工作被巧妙地转移到了加噪过程上。

8.3 Flow Matching 与 Rectified Flow：再简化一步

沿着"还能不能更省事"再走一步。Flow Matching (2022) 的思路是： 既然 diffusion 的成功来自"用回归代替 trace 计算"，那能不能干脆不碰 SDE，直接回归一个速度场？

做法就三条：

① 选路径
x_t = α_t x₁ + σ_t x₀
⟶
② 算目标速度
u_t = dx_t/dt（可解析）
⟶
③ 简单回归
L = ‖v_θ(x_t,t) − u_t‖²

完全不需要算 log-det，也不需要模拟 SDE。训练就是一个 MSE。

不同的 \((\alpha_t,\sigma_t)\) 选择，就复现出不同的方法：

路径\(\alpha_t,\ \sigma_t\)对应方法轨迹形状
线性 / OT 路径\(\alpha_t=t,\ \sigma_t=1-t\)Flow Matching直线
VP（方差保持）\(\alpha_t=\sqrt{\bar\alpha_t},\ \sigma_t=\sqrt{1-\bar\alpha_t}\)DDPM弯曲
VE（方差爆炸）\(\alpha_t=1,\ \sigma_t=\sqrt{\sigma_{\max}^{2t}}\)Score-based / NCSN弯曲

动手看一下这三种路径到底差在哪：

最终的统一

diffusion、score-based、flow matching、rectified flow，全都是"选一条从噪声到数据的路径，然后学它的速度场"， 区别只有三点：① 路径怎么选（直线？VP？VE？）、② 损失怎么构造（score matching？条件速度回归？）、 ③ 推理用几步（ODE 求解器？蒸馏成一步？）。

Rectified Flow：把轨迹拉直

Rectified Flow (2022/2023) 又往前走一步。既然直线路径采样最快，那就迭代地把轨迹拉直： 用当前模型生成配对 \((x_0,x_1)\)，再用这些配对去训练新模型，反复几轮， 轨迹越来越直，采样步数越来越少。

几何读法

轨迹越直，ODE 求解器需要的步数越少。最理想的情况是 \(x_t\) 就是一条直线， 那么一步欧拉法就能从噪声跳到数据。 Flow Matching 和 Rectified Flow 的核心工作，本质上都是在"路径空间"里做优化—— 不是让模型去拟合一条给定的弯曲轨迹，而是先设计一条好走的轨迹。 这是对 diffusion 思路的一次视角反转。

9.1 VAE：用变分后验补上缺失的账

从自编码器说起

自编码器很简单：编码器把 \(x\) 压成潜变量 \(z\)， 解码器把 \(z\) 还原回 \(x\)。目标是最小化重构误差。

但它不能生成

潜空间里没有任何结构约束。你随手取一个 \(z\)，解码出来是垃圾。 整个潜空间只有极少数点对应有意义的数据，其余全是"荒漠"。 能压缩，但采不了样。

关键一步：让编码器输出一个分布

VAE 的想法是：编码器不输出一个点，而是输出一个分布：

\[ q_\theta(z\mid x)=\mathcal{N}\!\big(\mu_\theta(x),\ \sigma^2_\theta(x)I\big) \qquad \text{先验}\quad p(z)=\mathcal{N}(0,I) \]

于是潜空间从"一堆孤立的点"变成"一片概率云"。要生成，就从先验采一个 \(z\)，解码。

但问题立刻来了：编码器产生的那堆小高斯云，和先验 \(N(0,I)\) 对得上吗？

如果编码器把不同数据点映射到离得很远、方差很小的地方，那这些区域在先验下的概率几乎为零—— 你根本采不到它们。采到的 \(z\) 落在云与云之间的空隙里，解码出来还是垃圾。

ELBO 的推导

我们要最大化 \(\log p(x)\)，但这个量算不出来（要对所有 \(z\) 积分）。标准技巧是"乘一项除一项"，再用 Jensen 不等式：

\[ \begin{aligned} \log p(x)&=\log\int p(x\mid z)\,p(z)\,dz\\[2pt] &=\log\int q(z\mid x)\cdot\frac{p(x\mid z)\,p(z)}{q(z\mid x)}\,dz\\[2pt] &\ge\ \mathbb{E}_{q(z\mid x)}\!\left[\log\frac{p(x\mid z)\,p(z)}{q(z\mid x)}\right]\\[2pt] &=\underbrace{\mathbb{E}_{q}\big[\log p(x\mid z)\big]}_{\text{重构项}}\;-\;\underbrace{\mathrm{KL}\big(q(z\mid x)\,\|\,p(z)\big)}_{\text{KL 项}} \end{aligned} \]

KL 项的几何意义：它在补账

本节最重要的一句话

KL 项就是在把编码器产生的那些"小概率云"往先验那边拽。

具体拽两个地方：

  • 如果某个数据点的后验均值 \(\mu\) 离原点很远，KL 里的 \(\|\mu\|^2\) 项就很大——把它拽回来。
  • 如果后验方差 \(\sigma^2\) 比 1 小很多，KL 里的 \(-\log\sigma^2\) 项就很大——把它撑大。

结果：所有数据点被编码成一堆互相重叠、且整体覆盖先验的高斯云。 只有这样，从 \(N(0,I)\) 采样才总能落到某个数据的邻域里，解码才有意义。

用第 8 章的话说：VAE 不知道真实的 \(\log|\det J|\) 是多少， 所以它用一个可算的 KL 去近似这笔账。 ELBO 之所以只是下界，就是因为它记的是近似账。

动手看一下这个"拽"的过程

重参数化技巧

重构项 \(\mathbb{E}_q[\log p(x\mid z)]\) 要对 \(q\) 求梯度， 但 \(q\) 是个分布，"从分布里采样"这个操作本身不可导。解法是把随机性隔离出来：

\[ z = \mu + \sigma\odot\epsilon,\qquad \epsilon\sim\mathcal{N}(0,I) \]

这样 \(z\) 变成了 \(\mu,\sigma\) 的确定性函数， 随机性全在 \(\epsilon\) 里（而它不需要梯度）。 看似只是个小技巧，实则是 VAE 能落地训练的关键——没有它，就得用高方差的 score function 估计量。

后验坍缩（Posterior Collapse）

一个真实会踩的坑

如果解码器太强（比如它本身就是个自回归模型），它可能完全忽略 \(z\)， 直接从 \(p(x\mid z)\) 里把 \(x\) 背出来。

此时 \(q(z\mid x)\) 退化到 \(p(z)\)、KL 趋近 0—— 目标函数看起来很漂亮，但 \(z\) 里不含任何信息，模型退化成了一个普通自编码器，采样出来全是垃圾。

对策：KL 退火（训练初期给 KL 项一个很小的权重，让模型先学会用 \(z\)，再慢慢加大约束）、 free bits（每维 KL 低于某个阈值就不惩罚）、或者用更弱的解码器。 VQ-VAE 用离散潜变量，从结构上缓解了这个问题。

为什么 VAE 生成的东西是模糊的

这是最常被问到的问题，答案有两层：

  1. 重构项是"期望"。 \(\mathbb{E}_q[\log p(x\mid z)]\) 要求解码器对 \(q\) 下的所有 \(z\) 都重建得好，而 \(q\) 是有方差的。 在"有多个合理答案"的地方，最优策略是输出它们的平均——像素上的平均就是模糊。
  2. ELBO 是下界，不是似然本身。它偏向保守的解。

对比一下：flow 用精确似然，所以没有这个"平均化"压力（但 flow 有可逆性这个自己的代价，见 7.8 节）。 每个家族都在付一种特定的代价。

9.2 GAN：不记账的代价与收益

极小极大博弈

生成器 \(G:z\mapsto x\)，判别器 \(D:x\mapsto[0,1]\)：

\[ \min_G\max_D\ \ \mathbb{E}_{x\sim p_{\text{data}}}\big[\log D(x)\big] +\mathbb{E}_{z}\big[\log\big(1-D(G(z))\big)\big] \]

几何上：\(G\) 试图把生成分布 \(p_g\) 搬到数据分布 \(p_{\text{data}}\) 上，\(D\) 试图找出两者的差异。

最优判别器给出 JS 散度

固定 \(G\)，最优判别器是：

\[ D^*(x)=\frac{p_{\text{data}}(x)}{p_{\text{data}}(x)+p_g(x)} \qquad\Longrightarrow\qquad \max_D V = 2\,\mathrm{JSD}\big(p_{\text{data}}\,\|\,p_g\big)-\log 4 \]

所以 GAN 的训练，本质上就是在最小化 JS 散度。 而这一步就注定了它的命运。

致命缺陷：JS 散度在高维下没有梯度

这是 GAN 训练不稳的根本原因

如果 \(p_{\text{data}}\) 和 \(p_g\) 的支撑集不重叠，那么：

  • JS 散度恒等于 \(\log 2\)，与两者离得多近无关；
  • 它的梯度恒等于零。

而这正是高维下的默认情况：两个分布各自集中在自己的低维流形上，两个流形相交的概率为零。

后果：判别器能给生成器的信号只有"你错了"，却不包含任何"你该往哪个方向走"的信息。 生成器只能靠运气乱撞。GAN 训练不稳、需要精心调平衡、动不动就崩，根源都在这里。

动手看一下：JS 散度与 Wasserstein 的分岔

WGAN：换一把尺子

Wasserstein-1 距离（推土机距离）：

\[ W(p,q)=\inf_{\gamma\in\Pi(p,q)}\mathbb{E}_{(x,y)\sim\gamma}\big[\|x-y\|\big] \]

几何含义极其直观：把 \(p\) 的"土"搬到 \(q\) 的形状上，平均需要搬多远。

关键性质：即使支撑集不重叠，\(W\) 依然随距离线性变化，梯度不会消失。

用 Kantorovich-Rubinstein 对偶把它变成可优化的形式：

\[ W(p,q)=\sup_{\|f\|_L\le 1}\Big(\mathbb{E}_{p}[f]-\mathbb{E}_{q}[f]\Big) \]

于是用一个 Lipschitz 常数受限的网络（叫 critic，不再叫判别器，因为它输出实数而不是概率）去逼近它。 限制 Lipschitz 的三种做法：权重裁剪（原始 WGAN，简单但粗暴）、 梯度惩罚（WGAN-GP，效果好）、谱归一化（实现最干净，现在最常用）。

模式崩塌的几何原因

这不是 bug，是目标的固有倾向

生成器只需要骗过判别器，不需要覆盖所有模式。 如果某个模式特别容易生成，\(G\) 会把质量集中堆在那里—— 因为把质量堆在一个模式上，比均匀分散到所有模式更容易骗过 \(D\)。 最小化 JS 散度并不要求覆盖所有模式，只要整体"看起来像"就行。

StyleGAN 的贡献

注意到 \(G\) 从 \(z\) 到 \(x\) 的映射高度非线性，\(z\) 空间里的方向没有语义——沿某个方向走，图像会以莫名其妙的方式变化。

StyleGAN 引入中间空间 \(W\)：先用一个 MLP 把 \(z\) 映射到 \(w\)， 再让每一层从 \(w\) 生成。 效果：\(W\) 空间比 \(Z\) 空间"解耦"得多 ——因为 MLP 可以学出一个把数据流形"拉直"的映射。加上逐层的噪声注入与风格调制，就能分别控制不同尺度的细节（姿态 vs 纹理）。

几何总结

GAN 完全不关心体积。没有似然、不需要可逆、不受拓扑约束、可以降维、可以跳变。 收益是样本可以非常锐利（不需要"平均"）； 代价是没有任何东西能保证覆盖整个数据分布。 这正是"不记账"这一选择的完整后果。

9.3 扩散模型：加噪与去噪

前向过程：把数据毁掉

\[ q(x_t\mid x_{t-1})=\mathcal{N}\!\Big(\sqrt{1-\beta_t}\,x_{t-1},\ \beta_t I\Big) \]

逐步加噪。关键性质是可以一步跳到任意 \(t\)（高斯卷积的闭式解）：

\[ x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon,\qquad \epsilon\sim\mathcal{N}(0,I),\qquad \bar\alpha_t=\prod_{s\le t}(1-\beta_s) \]
几何读法

\(x_t\) 就是"数据"和"一个标准高斯"的线性插值， 插值系数由 \(\bar\alpha_t\) 决定。 \(t=0\) 时是数据，\(t=T\) 时是纯噪声。 这正是第 8.2 节那条 VP 路径。

反向过程：把它救回来

第 8.2 节已经给出了答案：如果知道 score \(\nabla\log p_t(x)\)， 就能沿概率流 ODE 反向走回去。而 score 可以从加噪过程学到——给定 \(x_t\)，预测当初加了什么噪声：

\[ \nabla_{x_t}\log p_t(x_t)=-\frac{\epsilon}{\sqrt{1-\bar\alpha_t}} \]

所以"预测噪声"和"知道 score"是同一件事。这就是 diffusion 训练目标的全部来历。

下面这张图把"反向过程"画了出来——你可以亲手发射粒子，看它们怎么被速度场送回数据。

训练：一个去噪回归

\[ \mathcal{L}=\mathbb{E}_{t,\,x_0,\,\epsilon}\Big\|\,\epsilon-\epsilon_\theta(x_t,t)\,\Big\|^2 \]

随机采一个 \(t\)、一份数据、一个噪声，加噪后用网络预测噪声。**就是一个 MSE。**

和 FFJORD 对比一下

FFJORD 要算 \(\operatorname{tr}(\partial v/\partial z)\)——随机估计、有方差、训练不稳； 这里只要回归一个噪声。 这就是 diffusion 训练稳定的根本原因。 两者数学上是同一族模型（第 8.2 节），差别全在"怎么训练"上。

三种等价的参数化

同一个网络可以预测三样东西，它们互相可以换算：

预测目标换算关系特点
噪声 \(\epsilon\) —最常用，数值最稳，各 \(t\) 的损失尺度一致
干净数据 \(x_0\) \(x_0=(x_t-\sqrt{1-\bar\alpha_t}\,\epsilon)/\sqrt{\bar\alpha_t}\) 最直观，但 \(t\) 大时系数放大误差
score \(-\epsilon/\sqrt{1-\bar\alpha_t}\) 几何意义最清晰，是概率流 ODE 直接需要的量

采样：DDPM 与 DDIM

  • DDPM 采样：沿着反向 SDE 走，每步注入随机噪声。随机、步数多（几百到上千步）。
  • DDIM：把随机项去掉，变成确定性 ODE。更少的步数、可复现、可以插值。 DDIM 本质上就是概率流 ODE 的一种离散化——第 8.2 节那条式子的一种数值解法。

Classifier-free guidance

训练时随机丢弃条件，让同一个网络既能算有条件也能算无条件 score。采样时：

\[ \nabla\log p_\gamma(x\mid c)=\nabla\log p(x)+s\Big(\nabla\log p(x\mid c)-\nabla\log p(x)\Big),\qquad s>1 \]

\(s>1\) 放大条件的影响，样本更贴合提示词。代价是多样性下降。

几何读法

guidance 在潜空间里做了一次外推：把样本从"无条件分布"往"条件分布"的方向推过头一点。 推过头带来的结果是：更符合条件，但更集中在条件分布的众数附近，所以多样性降低。 这也是为什么 guidance 强度是一个典型的"质量 vs 多样性"旋钮。

为什么 diffusion 生成质量高

  1. 不需要可逆——网络可以是任意架构（U-Net、Transformer、MLP）
  2. 不需要算 log-det——损失是简单回归，训练信号干净
  3. 维度自由——可以在潜空间做，成本大幅降低（见 10.1）
  4. 没有"平均化"压力——每一项都是对单个噪声样本的回归，不是对分布的期望。这是它比 VAE 锐利的根本原因
  5. 训练任务多——每个 \(t\) 都是一个独立的训练任务，梯度信号密集

为什么采样慢

第 8 章讲过：因为路径是弯的。要把一条弯曲的 ODE 积准，就需要很多步。 把几十步压成一两步是当前最活跃的方向——第 10.2 节讲。

9.4 自回归模型：把联合分布拆成条件概率

最古老也最强大的思路

\[ p(x)=\prod_{i=1}^{n}p(x_i\mid x_{<i}) \]

把高维联合分布拆成一串一维条件分布。数学上完全精确，不需要任何近似—— 这是它和 VAE（下界）、GAN（无似然）最重要的区别。

它其实就是一种 flow

一个常被忽略的事实

回想第 7.2 节：autoregressive flow 的 Jacobi 矩阵是三角的， \(\log|\det|=\sum_i s_i(z_{<i})\)。 自回归模型就是一类 Jacobi 矩阵为三角的 flow， 只不过它不显式做"变换"，而是直接参数化条件分布。

所以它继承了 flow 的全部优点（精确似然、精确采样、训练可并行）和全部缺点—— 采样必须串行：第 \(i\) 维必须等前 \(i-1\) 维算完。第 7.2 节那个训练/采样对偶，在这里以最昂贵的形式出现。

三个代表

模型生成对象关键技术
PixelCNN图像，逐像素掩码卷积，保证每个像素只看左边和上边
WaveNet音频，逐采样点空洞（膨胀）卷积，指数级扩大感受野
Transformer / LLM文本，逐 token因果掩码自注意力

今天最强大的生成模型（大语言模型）就是这一类。 它同时也是唯一一个"既是 flow、又是当前 SOTA"的家族。

为什么 LLM 采样慢

生成 \(n\) 个 token 需要 \(n\) 次前向。 这就是自回归的宿命，也是"三角结构"这个设计的必然代价。

值得澄清一点：KV cache 优化的是每次前向的成本，不是前向的次数。 它让第 \(i\) 次前向不用重算前 \(i-1\) 个 token 的注意力，但串行的 \(n\) 步一步也省不掉。要打破这个，只能让整个序列并行生成——而那就不是自回归了。

9.5 能量模型：最古老的思路

定义一个能量函数，低能量 = 高概率：

\[ p_\theta(x)=\frac{\exp\big(-E_\theta(x)\big)}{Z(\theta)},\qquad Z(\theta)=\int\exp\big(-E_\theta(x)\big)dx \]
配分函数 Z 算不出来

\(Z\) 要对整个空间积分——在高维下完全不可行。 所以 EBM 既没法直接算似然，也没法直接做最大似然训练。

怎么绕开

方法做法几何图像
Langevin 采样 \(x\leftarrow x-\eta\nabla E(x)+\sqrt{2\eta}\,\xi\) 沿能量下降方向走，同时加噪声防止卡在局部低点
对比散度 (CD) 用 MCMC 采一些"负样本"，推高它们的能量 粗糙但能用，"把假样本的能量抬起来"
Score matching 直接学 \(\nabla\log p=-\nabla E\) \(Z\) 在求梯度时自动消掉！

第三行是关键：\(\nabla_x\log p_\theta(x)=\nabla_x\log\exp(-E)=-\nabla_x E(x)\)—— 常数 \(\log Z\) 求导就是零，配分函数彻底消失了。 这就是 score matching 的全部魔法。

与 diffusion 的关系

Diffusion 就是"多尺度的去噪 score matching"

在每一个噪声水平 \(t\) 上，学一个 score 场。 噪声大的尺度管全局结构，噪声小的尺度管细节。 这解释了 diffusion 为什么比单尺度 EBM 好训得多： 它把一个困难的 score matching 问题，分解成了一堆各自简单的小问题。 EBM 想用一张网络搞定所有尺度，自然难得多。

9.6 六族总对比

家族如何建模精确似然训练目标 采样主要代价
Flow 可逆双射 + 换元 ✔ 精确 最大似然，需算 log_det 快（一类并行） 可逆性 + 维度相等的硬约束
VAE 随机编码 + 解码 ✘ 下界 (ELBO) ELBO，需重参数化 快 生成模糊；后验坍缩
GAN 生成器 + 判别器对抗 ✘ 无 极小极大博弈 最快（一步） 模式崩塌；训练不稳
扩散 多尺度去噪 ✘（但可算变分下界） 噪声回归（MSE） 慢（几十步） 采样慢——但可被工程解决
自回归 \(\prod p(x_i\mid x_{<i})\) ✔ 精确 交叉熵（教师强制） 慢（串行 n 步） 串行采样的结构性宿命
EBM \(p\propto e^{-E}\) ✘（\(Z\) 不可算） 对比散度 / score matching 慢（MCMC） 配分函数不可算；MCMC 混合慢

9.7 为什么 diffusion 赢了（阶段性结论）

不是因为它"更好"，而是因为它在几个关键权衡上取了最好的位置。把每族的代价按"能不能被工程解决"分个类：

家族主要代价性质能否优化掉
Flow 可逆性 + 维度必须相等 + log_det 成本 数学上的硬约束 不能——这是微分同胚的定义决定的
GAN 模式崩塌 + 训练不稳 目标函数的固有性质（JS 散度无梯度） 很难——要换距离（WGAN）也只是缓解
VAE 生成模糊 下界目标 + 重构项是期望的性质 很难——除非放弃 ELBO
自回归 采样必须串行 三角结构决定的 不能——除非不做自回归
EBM 配分函数不可算 + MCMC 慢 数学性质 部分——用 score matching 绕开 \(Z\)
扩散 采样慢 纯工程问题 能——蒸馏 / 少步求解器 / 一致性模型
这就是答案

diffusion 是唯一一个"主要代价可以被工程解决"的家族。

其他家族的代价都刻在数学结构里：flow 的可逆性、GAN 的 JS 散度、VAE 的下界、自回归的三角结构、EBM 的配分函数—— 这些都不是"多花点算力"能解决的，而是定义本身带来的。

而 diffusion 的代价只有一个：采样需要多步。这是一个数值积分问题， 而数值积分问题有几十年的成熟工具箱。第 10 章讲的就是这个工具箱被用得有多狠。

还有一条同样重要的原因：架构自由

扩散模型对网络架构没有任何约束——不需要可逆、不需要三角、不需要切维度、不需要 Lipschitz 限制。

这意味着：当 Transformer 和大规模训练工程成熟之后，diffusion 是唯一能直接"拿来就用"的生成框架。 LLM 领域的全部工程积累（并行训练、混合精度、FlashAttention、分布式）可以原封不动搬过来。 其他家族都要先把架构"改造"成符合自己约束的形状，这本身就是巨大的摩擦。

一句话总结第 9 章

每一族都在用某种方式回避"精确记账"的困难，而每一次回避都换来一个特定的、往往难以消除的代价。 diffusion 之所以胜出，是因为它回避得最彻底（损失只是回归）， 而它留下的唯一代价（采样慢）恰好是最容易被工程手段解决的一种。

10前沿与收敛：把代价一项项消掉

第 9 章得出结论：diffusion 胜出的原因是它唯一的代价（采样慢）是工程问题。 这一章讲的就是这个"工程问题"被解决到什么程度了，以及整个领域正在收敛到什么形状。

10.1 Latent Diffusion：先压缩，再扩散

扩散模型最直接的代价是算力：在 \(512\times512\times3\) 的像素空间上跑几十步网络，非常昂贵。

Stable Diffusion 的核心思路很朴素：先压缩，再在压缩后的空间里扩散。

① 编码
用 VAE 把图像压到潜空间
⟶
② 潜空间扩散
在 z 上跑完整的扩散过程
⟶
③ 解码
把 z 解回像素

典型配置是 8× 下采样，于是空间尺寸缩小 \(8^2=64\) 倍——计算量直接降两个数量级。

一个值得注意的角色转换

在这里，VAE 的职责变了：它不再需要提供精确似然，只是一个"可逆的压缩器"。 所以用 VAE 还是用 flow 都无所谓——只要压缩-解压足够保真、潜空间足够"规整"就行。 第 9.1 节那些困扰 VAE 的问题（模糊、后验坍缩），在这个新角色下大半不再重要： 反正扩散过程会在潜空间里把分布学准。

还有一个不那么显然的好处：潜空间比像素空间"语义更规整"。 像素级的细节（纹理、噪声）被压缩掉了，留下的更多是结构信息。在更规整的空间里做扩散，等于降低了任务难度。

10.2 蒸馏与一致性模型：把几十步压成一步

第 8.3 节说过：轨迹越直，需要的步数越少。有三条路线在朝"一步生成"逼近。

路线一：渐进蒸馏（Progressive Distillation）

学生模型学习"用一半的步数达到老师的输出"。反复减半： \(1024\to512\to256\to\dots\to2\to1\)。

几何读法：每一次蒸馏，都是在让学生的轨迹用更少的折线去逼近老师的曲线。 折线少了，每一段就必须更直。

路线二：一致性模型（Consistency Models）

这个思路更彻底，直接对着"一步到位"设计。要求学到一个函数 \(f(x_t,t)\)，满足：

\[ f(x_t,t)=f(x_{t'},t')\qquad\text{对同一条轨迹上的任意 }t,t' \]
几何读法

它要求：同一条轨迹上的所有点，都映射到同一个终点。 也就是说，把整条曲线"塌缩"成它的起点（或终点）。

配上边界条件 \(f(x_0,0)=x_0\)，就得到： \(x_0=f(x_T,T)\)——从纯噪声一步跳到数据。

训练方式有两种：蒸馏（用老师模型跑出轨迹，让学生学"同轨迹同输出"）、 或者独立训练（用自己的当前模型构造轨迹，加一个度量约束）。

路线三：Rectified Flow / Reflow

第 8.3 节讲过。用当前模型生成配对，再用配对训练新模型，迭代地把轨迹拉直。

路线核心操作几何本质
渐进蒸馏步数反复减半用更少的折线段逼近原曲线
一致性模型同轨迹映射到同一点把整条轨迹塌缩成一个点
Rectified Flow迭代重训拉直轨迹把曲线掰直成直线

三条路线目标一致：逼近那个"一步到位"的理想映射。 区别只在于——是"用更少的折线逼近曲线"、"把曲线塌缩成一个点"、还是"把曲线掰成直线"。

10.3 架构合流：Diffusion Transformer

Diffusion Transformer（DiT）做的事情很简单：把 U-Net 换成 Transformer。

它的意义远超"换个骨干网络"：

它标志着扩散的架构约束被彻底解除

回想第 9.7 节那句话——diffusion 对网络架构没有任何约束。 DiT 把这句话兑现了：生成模型可以直接复用 LLM 的架构与全部工程优化 （并行训练、混合精度、FlashAttention、分布式切分、KV 缓存式的推理优化）。

这解释了一个观察：近几年图像/视频生成与语言模型的技术栈正在快速合并。 两者的差异只剩下"输入是什么"和"训练目标怎么构造"，底层的架构、并行策略、缩放规律（scaling law）几乎是同一套。

回看第 9.7 节的结论

我们说 diffusion 赢在"代价可以被工程解决"。DiT 是这个论断最强的一层证据： 不但代价能被解决，连架构都可以直接借用另一个领域的成熟成果。 而 flow 的 coupling 层、GAN 的对抗结构、自回归的因果掩码，都做不到这一点——它们各自锁死在自己的约束里。

10.4 回到记账视角：每一代都在偷懒

最后，把所有家族放回第 8 章那把尺子上，看它们各自"绕开了什么"：

家族面对"体积记账"这道题，它的选择
Flow不绕，硬算。精确求 log_det——代价是可逆性这个硬约束。
VAE不写真账，用 KL 近似。代价是只有下界，生成偏模糊。
GAN根本不记账。代价是没有似然、模式崩塌。
自回归用三角结构让账变简单。代价是采样串行。
EBM绕开配分函数 \(Z\)，只学 score。代价是 MCMC 慢、混合难。
扩散用回归绕开 trace，用多尺度分解绕开"难采样"。代价只有采样步数。
Flow Matching连 SDE 都不碰，直接回归一个速度场；再进一步，把路径也设计好。
整条主线的形状

把第 8 到第 10 章连起来读，会看到一条清晰的趋势：

生成模型的演进史，就是一部"如何更聪明地偷懒"的历史。

Flow 说：我精确记账——但要付出可逆性的代价。
VAE 说：我记不准，但我能用 KL 近似。
GAN 说：我不记账——但代价是学不全。
自回归说：我把账做成三角的，好算——但采样慢。
EBM 说：我连分母都不算——但得靠 MCMC 慢慢摸。
Diffusion 说：我不算 trace，我用回归代替；我不算难采样的分布，我把它拆成上千个简单的小问题。
Flow Matching 说：我连随机过程都不要了，就回归一个速度场；而且路径我来设计，不用学一条弯的。

每一代新方法，都是在"记账"这件事上找到一个更聪明的偷懒方式。 而每次偷懒都会留下一个新的代价——能不能赢，就看那个代价能不能被工程吃掉。

写在最后

教程开头说：Jacobi 矩阵负责"形状怎么变"，行列式负责"体积怎么变"。

走完这十章，这句话可以再往前推一步了：

整个领域的地形图

整个生成模型领域的地形，某种意义上就是一张"体积记账好不好做"的地图：

  • 账好算 → 精确似然的模型（flow、自回归）
  • 账难算但可以近似 → 下界（VAE）
  • 账不算了 → 无似然但自由的模型（GAN）
  • 换一种方式记账 → 回归代替积分（扩散、Flow Matching）
  • 账恰好是零 → 保体积模型（NICE、无散 CNF、哈密顿流）
  • 账发散了 → 你撞上了几何上的硬约束（tanh 尾巴、重尾分布）

以后再遇到任何一个生成模型的新工作，还是那三个问题：

  1. 它的映射是什么？确定性还是随机？可逆还是不可逆？
  2. 它怎么记账？算 log_det、近似它、绕开它、还是换成回归？
  3. 它为此放弃了什么？那个代价是数学上的硬约束，还是可以被工程解决的？

第三个问题最关键。一个模型能不能流行起来，很大程度上不取决于它有多优雅，而取决于它的代价长在什么地方。
